# Darlehen – Rückzahlungen

Kleine App zum Notieren von Rückzahlungen eines Darlehens. Nur eine Datei: `index.html`.

- Jede Person führt ihre eigene Liste: Die Einträge bleiben im Browser des Geräts, auf dem sie gemacht werden.
- **Sicherung speichern** erstellt eine Datei (`Darlehen_…json`), **Sicherung laden** holt sie auf ein anderes Gerät zurück.
  Der Punkt ● am Knopf zeigt: seit der letzten Sicherung kam etwas dazu.
- **Viele alte Zahlungen auf einmal nachtragen**: Liste einfügen (Datum Betrag [Bank/TWINT/Bar] [Notiz]), prüfen, speichern.
- Tipp iPhone: Seite in Safari → Teilen → «Zum Home-Bildschirm». So bleibt der Speicher sicher erhalten.
